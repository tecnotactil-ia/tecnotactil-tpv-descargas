# 🎁 Herramientas para la comunidad

Programas **completamente gratis** de [TecnoTactil](https://www.tecnotactil.com)
para todos los usuarios. Sin registro, sin anuncios y sin límites.

Página oficial: https://www.tecnotactil.com/herramientas

| Herramienta | Qué hace | Windows | Linux |
|---|---|---|---|
| **Bajar Vídeos** | Descarga vídeos de YouTube y muchos sitios más, con playlists y progreso | [BajarVideos.exe](BajarVideos.exe) | [bajar-videos-linux.tar.gz](bajar-videos-linux.tar.gz) |
| **Vídeos pal Carro** | Convierte vídeos al formato de los reproductores de carro (MP4 · H.264 · AAC) | [VideosPalCarro.exe](VideosPalCarro.exe) | [videos-pal-carro-linux.tar.gz](videos-pal-carro-linux.tar.gz) |

- **Windows:** descarga el `.exe` y ejecútalo, no necesita instalación (todo va incluido).
- **Linux:** descomprime el `.tar.gz` y ejecuta `./instalar.sh` (los requisitos vienen en el `LEEME.txt`).

Verifica tu descarga con [SHA256SUMS.txt](SHA256SUMS.txt).
